2. what is the difference between setInterval() & setTimeout() ?
    The main difference between setTimeout() and setInterval() in JavaScript is how many times they execute a function.
    - setTimeout() → executes a function once after a specified delay.
    - setInterval() → executes a function repeatedly at a specified interval until you stop it.

    setTimeout(() => {
        console.log("Hello JavaScript");
    }, 2000);

    setInterval(() => {
        console.log("Hello JavaScript");
    }, 2000);

3. what is promise in JavaScript ?
    A Promise in JavaScript is an object that represents the eventual result of an asynchronous operation. 
    It can be in three states: 
        pending, 
        fulfilled, or 
        rejected.
    For example, imagine ordering a pizza online. The order is pending while the pizza is being prepared. If the pizza is delivered, the Promise is fulfilled. If the order fails, the Promise is rejected.
    In JavaScript, we use `then()` to handle success and `catch()` to handle errors.

    One final thing to remember:
    - Promise → represents a future result.
    - .then() → handles success.
    - .catch() → handles failure.
    - .finally() → runs after the Promise settles, whether it succeeds or fails.
